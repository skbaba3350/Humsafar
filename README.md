# ہم سفر (Humsafar) - پائلٹ ورژن ۱.۰

سنجیدگی سے پہلی یا دوبارہ شادی کا باوقار رشتہ تلاش کرنے والے بالغ افراد کے لیے ایک نجی، محفوظ اور باعزت ویب پلیٹ فارم۔

یہ نظام خاص طور پر ان افراد کی ضروریات، احساسات اور رازداری کو مدنظر رکھ کر بنایا گیا ہے جو معذوری (Disability) یا وہیل چیئر کے ساتھ باوقار زندگی گزار رہے ہیں، طلاق یافتہ ہیں، یا جن کے شریکِ حیات وفات پا چکے ہیں۔

---

## ۱۔ بنیادی خصوصیات اور ورک فلو

1. **ریفرنس ڈیزائن سے مکمل مطابقت (`ui.png`):**
   - **ہیڈر:** اردو نستعلیق لوگو، سنہری لکیر، نیویگیشن لنکس، لاگ اِن اور پروفائل رجسٹریشن کے واضح بٹنز۔
   - **ہیرو سیکشن:** گہرا رانی و مہرون پس منظر، پھولدار کونے، نستعلیق عنوان «ایک خوبصورت نئے سفر کی شروعات»، اور سنہری محراب میں شادی شدہ مسرور جوڑے کی تصویر (جس میں وہیل چیئر صارف دولہا باوقار انداز میں شامل ہے)۔
   - **تین مراحل:** اپنا تعارف بنائیں، دلچسپی کی درخواست بھیجیں، باہمی رضامندی سے بات شروع کریں۔
   - **خوش آمدید سیکشن:** مختلف عمر کے بالغ افراد کی باوقار علامتی تصویر اور خیرمقدمی متن۔
   - **رازداری کا بینر:** جامنی پٹی پر تصویر کا اختیار، باہمی رضامندی کی گفتگو، بلاک اور رپورٹ کی سہولت۔
   - **عام سوالات:** اصل ایکارڈین کے ساتھ اصلی پالیسی جوابات۔
   - **اختتامی دعوت و فوٹر:** فعال رجسٹریشن بٹن، لوگو اور تعارف، رازداری، شرائط اور مدد کے فعال لنکس۔

2. **عوامی رازداری کی مکمل گارنٹی:**
   - عوامی ہوم پیج پر کسی ممبر کا نام، تصویر یا رابطہ ہرگز ظاہر نہیں ہوتا۔
   - ممبرز کی تصاویر نجی اسٹوریج میں رکھی جاتی ہیں اور صرف انہی کو دکھائی دیتی ہیں جنہیں ممبر خود انفرادی اجازت فراہم کرے۔

3. **اکاؤنٹ اور سیکیورٹی:**
   - کم از کم ۱۸ سال کی عمر کی تصدیق (کلائنٹ اور ڈیٹا بیس دونوں پر پابندی)۔
   - ڈرافٹ محفوظ کرنے، پیش منظر دیکھنے اور جائزے کے لیے جمع کروانے کی سہولت۔
   - پروفائل کی ایڈمن منظوری کے بعد ہی پورٹل پر تلاش ممکن ہے۔

4. **دلچسپی کی درخواستیں اور نجی گفتگو:**
   - موصول شدہ اور بھیجی گئی درخواستوں کا انتظام۔
   - درخواست قبول ہونے پر خودکار ٹرانزیکشن کے تحت ایک واحد نجی گفتگو شروع ہوتی ہے۔
   - یکطرفہ، بلاک شدہ، یا غیر متعلقہ افراد پیغامات نہیں بھیج سکتے۔

5. **شکایات اور ایڈمن پینل:**
   - جعلی پروفائل، ہراسانی یا رقم مانگنے کی فوری رپورٹنگ۔
   - اگر مخصوص میسج رپورٹ کیا جائے تو رازداری برقرار رکھتے ہوئے ایڈمن کو صرف وہی میسج دکھایا جاتا ہے۔
   - ایڈمن کے پاس پروفائل منظوری، ترمیم کی واپسی اور اکاؤنٹ معطلی کے مکمل اختیارات مع آڈٹ لاگ۔

## ۳۔ اکاؤنٹ کی حفاظت

عوامی لاگ اِن صفحے پر کوئی ٹیسٹ اکاؤنٹ یا مشترکہ پاس ورڈ موجود نہیں ہونا چاہیے۔ ایڈمن کی معلومات الگ فراہم کی جاتی ہیں، اور انہیں Git یا ویب سائٹ میں محفوظ نہ کریں۔ لوکل seed صرف الگ ٹیسٹ ڈیٹا بیس کے لیے ہے، production کے لیے نہیں۔

## ۴۔ چلانے اور ٹیسٹ کرنے کی ہدایات

### ۱۔ لوکل سپابیس اسٹارٹ کریں:
```bash
supabase start
```

### ۲۔ ڈیٹا بیس مائیگریشن اور سیڈ ڈیٹا لوڈ کریں:
```bash
supabase db reset --yes
```

### ۳۔ این پی ایم ڈیپینڈینسز انسٹال اور سرور چلائیں:
```bash
npm install
npm run build
npm run start
```
ویب ایپ `http://127.0.0.1:3000` پر لائیو ہو جائے گی۔

### ۴۔ تمام اینڈ ٹو اینڈ ورک فلو ٹیسٹس خودکار چلائیں:
```bash
python test_humsafar_workflow.py
```
یہ اسکرپٹ سائن اَپ، ایج تصدیق، رازداری چیک، ایڈمن ریویو، دلچسپی کی درخواست، ڈپلیکیٹ درخواست کی ممانعت، نجی چیٹ، تصویر کی اجازت اور منسوخی، اور بلاک/رپورٹ کے تمام ۱۴ ٹیسٹ خودکار تصدیق کرتا ہے۔
